# Model review execution temporarily suspended

## Scope

This change follows the request to bypass review nodes without deleting their implementation. New runs follow Planning → Analysis → Report. The review, comparison and review-triggered closure implementations, rubrics, schemas and historical records remain in the source tree. Re-enabling review requires a deliberate source change; no UI preference or existing depth/speed setting enables it.

- The Graph does not schedule independent review, comparison review or review-triggered closure.
- Internal DSH and external ACP reject those actions before creating or resuming a model worker. The legacy host Reviewer is also disabled.
- Existing incomplete review actions are retained as skipped historical actions. Already saved analysis and valid closure output remain available. Existing completed reports are not rewritten.
- A resumed run with previously active workers still requires the existing host-quiescence proof. This change does not stop user processes or alter user profiles.
- `review_policy=disabled` means that analysis can complete without a model-review verdict. The UI and report say that model review was not performed; they do not manufacture PASS.
- Identity, path boundaries, frozen inputs, revision checks and structural validation remain in place. Manual case acceptance remains available.
