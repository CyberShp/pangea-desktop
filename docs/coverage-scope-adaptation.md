# 覆盖率目录下钻适配（2026-09-28）

## 行为

- 查询使用完整 `--scope`，首段为平台模块名；可选择递归或仅直属文件。
- 客户端仍接受旧 `module` 输入字段，并转换为完整 scope；旧版平铺 combined JSON 文件仍可导入。执行查询需要支持新协议的内网 skill。
- 逐页采集 `uncovered` 与 `indeterminate`，仅以 `has_more=false` 结束。来源、报告时间戳、范围或汇总发生变化时查询失败，不把混合快照导入为完整资产。原始页保存在查询目录。
- summary、auto、llt 分开解释；默认 summary，可切换。首选来源缺失时展示实际来源与警告。原始资产保留全部来源，结构化分析记录只采用本次选择的来源。
- 分支 count=0 与 count=- 分开保存；未判定分支 count=null，不计为零覆盖。完整匹配诊断随 Run 冻结供分析读取。
- 文件数展示 scope_unique_file_count，不把分页条目数当唯一文件数。
- 覆盖率分析的代码目标取用户源码范围与查询目录的交集。完整目录按路径段匹配，可带仓库前缀；显式参考源码独立保留。未能匹配时不自动退回父模块。
- 无数据、范围无命中、部分来源缺失及查询错误分别保留；partial 即使分页取完仍为 partial。
