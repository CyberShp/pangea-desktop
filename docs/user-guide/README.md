# PANGEA Desktop 指南上传说明

这份文档包面向首次使用 PANGEA Desktop 的用户，包含完整操作正文和可独立上传的配图。

## 文件用途

| 文件 | 用途 |
| --- | --- |
| `user-guide.md` | Wiki 正文。使用标准 Markdown 标题、表格和相对图片链接。 |
| `assets/` | 正文使用的 20 张 PNG 配图，以及操作路线图的 SVG 源文件。 |
| `index.html` | 离线图文预览。解压后双击打开，支持目录导航、图片放大和打印。 |
| `evidence/index.html` | 真实分析案例的离线阅读页，分别展示原记录、冻结源码与评审建议。 |
| `evidence/*.json` | 两次历史 Run 的记录摘录、源码节选及来源哈希。 |
| `source-record.json` | 维护用的源码版本、配图来源和文件校验记录。 |

## 上传到 Wiki

1. 解压整个文档包，先打开 `index.html` 检查正文和图片。
2. 在 Wiki 新建页面，标题使用“PANGEA Desktop 新手使用指南”。
3. 使用该 Wiki 的 Markdown 导入功能导入 `user-guide.md`。
4. 如果平台支持本地相对图片一并导入，保持 `assets/` 的目录结构。否则，将 `assets/` 中的 PNG 上传到页面，并替换正文中的对应图片地址。
5. 将 `evidence/index.html` 的内容作为子页面或附件导入，并上传 `evidence/` 内的 JSON。平台不支持 HTML 附件时，可从证据阅读页复制正文到子页面；源码行号与原记录说明应一并保留。
6. 将正文中的 `evidence/index.html` 及其 `#a`、`#b` 链接替换为目标平台的子页面或附件地址，再检查 20 张图片、图注、表格、章节跳转和 Windows 路径。

如果富文档编辑器只支持粘贴正文，可从浏览器预览分节复制，再按图注位置上传配图。图片地址以目标平台保存后返回的地址为准。

图 1–17 保留 Desktop `a23cd31`、工作台 `7cc5179`、引擎 `7aa7abc` 基线的界面样例，使用隔离的示例数据；图 18–19 是历史真实产物的证据阅读页节选。操作文字适用版本见下文，上传时保留配图基线说明、案例的来源版本与状态、原记录和评审建议的区分。页面开头如由 Wiki 自动显示标题，可删除重复的一级标题。

正文保留首次操作主线；真实案例解释判断依据；源码更新和故障排查可独立查阅。无需把写作框架名作为 Wiki 栏目名。
