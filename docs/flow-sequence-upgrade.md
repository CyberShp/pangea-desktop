# 流程分析、独立 SVG 与时序图改进

> 历史记录：2026-10-21 起已移除 Archify。当前三种图由分析 Agent 提供结构化事实、工作台本地渲染；独立生图任务与排版返修不再执行。现行交付与升级验证见 [原生图表](native-diagrams.md)。以下内容保留为当时设计与验收记录。

本次改动跨 pangea-agent、dsh-pangea 和 Desktop 内置 Archify。发布时必须一起更新组件锁定提交。

## 已定位的问题与处理

- 流程图连线 hover 改变 React 状态，并在画布前插入详情，导致画布位置变化和反复进入/离开。现在 hover 仅局部样式变化，点击或键盘确认后才展示详情，详情放画布之后。
- SVG 原导出只序列化图形，页面绑定的 React 事件不会随文件保存。现在流程图 SVG 使用本地固定交互脚本和转义的图数据，支持节点、边和路径选择及键盘操作。PNG 保持静态。浏览器直接打开 SVG 才能运行其交互；图片预览器或作为 img 嵌入可能只显示静态图。
- 大图折叠原来会隐藏部分判断、异常、错误传播、恢复及出口节点。现在这些关键节点保留，只折叠其他次要节点，选中路径仍展开其节点。
- 节点和边两份路径序列可能不一致；UI 与投影原来还有各自不同的检查逻辑。现在共用准确的路径解析，诊断给出字段下标、期望端点与实际端点，保留已核实片段，不猜平行边或自动修改语义。
- 已有 stable-v1 路径诊断接入 result_write 的 warnings 响应，原 worker 可以在同一回合按源码修正并 supersedes 原记录。写入不因该 warning 被拒绝，不增加自动续接或完整复核。

## 分析指导

GitHub 筛选后，将 softaworks/agent-toolkit 的 mermaid-diagrams 和 WH-2099/mermaid-skill 的适用表达方法固定版本并适配到产品规则。来源、版本和许可见 pangea-agent 的 docs/diagram-guidance-sources.md 与 Companion src/diagram-guidance-sources.md。

流程分析使用新 Run 冻结的 scene_flow 与 scene_common_review：沿判断、事件、提前退出追到实际处理、状态/资源变化和出口。recv_fin、recv_rst 等是触发条件；源码存在的实际处理须用节点表达。正常关闭与预期拒绝不因此成为产品缺陷。规则不设置机械节点数量或语义门禁。

时序图在业务流程页提供独立入口，复用已有独立图任务、冻结源码范围与本地渲染。先核实参与者和消息因果关系，再绘请求、响应、状态变更与清理。支持 alt/else、loop、opt 片段、全屏、静态 SVG 和交互 HTML 导出；当前不支持 par 或嵌套片段，须明确局部范围及未知并发顺序。静态源码图不能作为运行时轨迹证明。

## 兼容与验证边界

历史 Run 继续使用原冻结规则，不改写用户记录。旧数据缺失异常节点，需要原 worker 结合源码补充或新建分析；重新导出不能凭空恢复未分析的行为。用户报告中的具体路径原始 JSON 未提供，因此本次验证覆盖相同结构的错配、平行边、循环和缺失尾边，不能宣称已修正那些历史记录。

交付前验证包含路径写入警告/同 worker 修正、前端节点路径选择/重复悬停、独立 SVG 脚本执行/内容转义、时序任务与渲染/片段边界、插件构建及 Desktop 类型检查。Linux 环境缺 Windows 实机和可用 Chromium，未宣称完成 Electron 实机视觉验收或真实 NGA/CodeAgent 分析质量验收。

2026-10-20 本地结果：Companion 全量 669 通过、10 跳过、0 失败；Desktop 流程与时序渲染 19 通过；Python 路径写入/修正及冻结合同 8 通过；worker 指针同步检查、Desktop typecheck/build 通过。完整 flow_stability 验证入口因环境缺少 langgraph 未运行，路径专项已用独立入口覆盖；不将合成用例结果当成真实模型分析质量证明。
