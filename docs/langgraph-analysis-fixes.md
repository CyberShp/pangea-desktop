# LangGraph 内网测试反馈修正

## 行为变更

- 资产提取任务冻结所选资产类型的说明和单类型结果 schema。类型不符时，同一 worker 最多自动修正一次；仍不符则等待处理，保留原始结果与会话续接入口。
- 用例沿用 behavior-test-v1 的既定结构。显示、复制和报告兼容已观察到的 precondition/test_steps/step 等别名，逐步配对操作与预期，不改写原始分析记录。
- 外部 ACP 分析单元最多三个并发；宿主 CLI 和会话索引写入串行。失败后停止新增派发，在途单元完成入库，成功结果保留。复核阶段保持其依赖顺序。
- 标准型保留独立盲审后对照复核；速度型直接对照锁定的分析结果，不执行独立盲审，报告标明模式。沿用冻结的运行合同，不切换既有运行模式。
- 分析时顺带识别有证据的业务风险，以 kind=risk 单独保存，优先关联已有用例；不新增扫描阶段、风险数量指标或重复风险用例。复核同步检查风险依据。风险面板说明当前记录状态，零条不表示系统安全。

## 边界与内网验收重点

本轮未验证真实模型的风险发现质量、NGA 模型列表获取或 Windows 内网端到端表现，未生成 Windows 正式安装包。三个模型会话可能增加瞬时资源及服务配额压力；速度型失去盲审的独立视角，可能遗漏与初次分析相同的盲点。测试耗时不代表真实模型提速比例。

内网重点确认：同一资产不同文件格式能正确入库；分析阶段最多三个 worker；每个用例同时显示操作与预期；有证据的风险进入风险面板并关联用例；速度型报告明确未执行盲审。已有运行使用原冻结说明，验证新说明需新建运行。
