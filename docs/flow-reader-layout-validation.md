## 最终交互

- 顶部集中选择流程，切换“流程阅读 / 流程图”。分析导航按实际项目数横排，窄窗口可横向滚动。
- 阅读区左侧展示紧凑主干及各步骤的分支数量，右侧只阅读当前步骤的分支；未挂接步骤的分支有独立入口。
- 分支可按条件、处理及回接搜索，结合类型、风险、待确认或未关联用例筛选。每页 12 条，列表独立滚动；翻页和筛选重置列表滚动位置。
- 选择分支后展示完整条件、处理、结果、状态和关联证据/用例；支持定位回接步骤。步骤细节可展开，旧格式内容保留。
- 图表单独使用内容区。流程总览提示按步骤与类型组织分支；“绘制本页分支”只提交当前页的编号范围，适合密集流程分批查看。
- 局部范围保存在派生图 manifest，冻结图上下文只包含这些分支，主干作为定位上下文；界面显示局部范围，修订图继续继承范围。没有修改主 Run 的语义或报告。
- 画图在后台执行，页面保留在图表视图；需要时通过“打开画图会话”进入会话。
