## 实现与权限

当前候选：模块 Skill 1.4.9，覆盖率 Skill 1.1.11。Reviewer 暂停在计划完成处，宿主调用 `runs verify-cases`，把实际输出、退出码、归档用例/程序和源码哈希交回同一 Reviewer。需要修订时续接原 Producer，旧证据不覆盖。正式输出再复核。

初期支持 Windows 上的自包含 C 探针；以 `PANGEA_CASE_CC` 指定已存在、受信任且兼容 GNU 参数的 C 编译器（Zig 使用 cc 子命令）。不自动安装或打包编译器，不运行项目构建脚本。编译器使用当前用户权限和自身标准库缓存；生成的程序使用无能力 AppContainer、独立临时目录、只读源码副本及 Job 限制。编译超时45秒，单探针执行10秒，内存256MiB，单进程。不能声称编译阶段也处于 AppContainer。

不支持的语言、依赖、硬件、初态不明确或环境不可用记录未验证；不允许直接在普通进程执行作为降级。单例非零退出或超时不会终止整个 Run。模型判断语义和可采纳性，宿主只提供事实。源程序/用例不由机械层修改。用户停止任务时取消当前 CLI 及其子进程。
