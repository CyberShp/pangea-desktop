# 资产管理与新建分析选取体验

五阶段版本已发布到三个仓库的 `feat/module-analysis-five-stages`：Agent `8ae1fb5`、DSH `368c1b2`、Desktop `5241a1f`。该组合可独立起构建。

资产优化最初在 `feat/asset-workspace-ux` 本地分支完成。本轮按用户要求合入 `feat/module-analysis-five-stages` 并构建；Agent 无新改动，Desktop 更新 DSH 组件锁。测试构建仅由本功能分支的 `.github/module-analysis-build-trigger` 文件变更触发，默认 test / 1.0.2，普通代码推送不触发。

## 已确认原因

- 新建分析默认发送 repository_id，Python 资产列表要求 repository_ids 精确包含该仓库。普通导入不会自动写仓库标签，因此无标签资产被排除。资产管理的入口直接传 asset_ids，不经过这个筛选，形成两条入口行为不一致。
- 选择器只加载一次，空数组也被缓存；重新打开时直接返回，导入或审核后的新资产无法在原表单刷新。旧实现最多读取第一页 100 个资产。
- 导入、方法论、筛选列表、多条资产详情及审核/归档/编辑按钮在同一长页展示。
- act 捕获保存错误后未返回成功与否，导入、编辑和逐条审核调用方仍清空表单。只修改审核备注还会丢失已有决定。

## 新交互

| 入口 | 行为 |
| --- | --- |
| 资产库 | 紧凑列表，搜索、类型与状态筛选；选择资产或进入详情 |
| 待审核 | 只列待审核资产，进入详情查看依据并审核 |
| 方法论 | 独立查看候选、启用状态和检查项；沿用已有生成入口 |
| 已归档 | 查看和恢复归档资产 |
| 导入资产 | 独立导入视图；文件选择为主，本机路径按需展开；重复内容可查看已有资产 |
| 资产详情 | 只显示当前资产；编辑、规范化、审核、归档在此操作，返回保留列表筛选 |
| 新建分析 | 默认全部可用资产；可主动选择仅关联当前仓库，支持搜索、类型筛选、分页、刷新；跨页保留选择与已读取名称 |

新建选择器关闭再打开会重新读取；筛选变更取消旧请求，迟到响应不会覆盖当前结果。空库和筛选无结果分别提示。仓库标签作为用户选择的筛选条件，不新增授权语义，不改写历史标签。

保存失败保留导入文件、预览、编辑信息及审核草稿。只修改备注保留已有决定；审核后刷新当前详情。列表时间显示 UTC+8。内容哈希、内部路径、允许步骤等实现细节不再占据主要操作区，底层已有数据合同保持不变，不新增检查。
